STYLE ANCHOR
============

Pick ONE of the three options below, then set STYLE_KEY in generate.py to its
key (e.g. "bilibin"). The chosen block is prepended to every prompt, identical
across all 90 images. This is the single biggest knob for "do all banners look
like one set".

Recommendation: BILIBIN.
- Strongest "Russian fairy tale book" association for players.
- Most consistent in modern image models — has appeared in plenty of training
  data tagged "Bilibin", "Russian lubok illustration", "Russian art nouveau
  fairy tale".
- Reads well at small banner sizes (decorative, high-contrast, clear silhouettes).

If the test batch under "bilibin" feels too flat / too "book illustration",
switch to "vasnetsov" for richer painterly depth. "lubok" is the most
stylised — only pick it if you want a deliberately naive folk-print look.

Each block ends with the SAME shared suffix so all three options behave the
same way regarding text, framing, and palette.
