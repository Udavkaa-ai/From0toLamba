# Купеческие гильдии — Спецификация (Сезон 2)

> Статус: **дизайн утверждён**, реализация запланирована после завершения Сезона 1.
> Старт: **15 мая 2026**. Финал: **12 июня 2026**.

---

## Концепция

Гильдия — команда от 3 до 5 игроков со званием Мудрец и выше, которые совместно
выбирают дела, вкладывают реальные Звёзды Telegram и делят результат по итогам сезона.

---

## Требования к участникам

| Параметр | Значение |
|---|---|
| Допустимые чины | Мудрец, Боярин, Князь |
| Минимум участников | 3 |
| Максимум участников | 5 |
| Членство | Только одна гильдия одновременно |
| Выход в середине сезона | Запрещён |

---

## Валюта сезона — Золотые

Звёзды Telegram конвертируются в **Золотые** при вложении в дело:

```
1 ⭐ = 100 Золотых
```

Золотые — внутренняя счётная единица. Обратно в Звёзды не конвертируются.
По итогам сезона прибыль пересчитывается в TON по рыночному курсу на 12 июня.

---

## Ставки по чинам

Каждый участник вкладывает фиксированную сумму за каждое одобренное дело:

| Чин | Звёзды за дело | Золотых за дело |
|---|---|---|
| Мудрец (ANALYST) | 15 ⭐ | 1 500 |
| Боярин (SHARK) | 25 ⭐ | 2 500 |
| Князь (LAMBO_SENSEI) | 50 ⭐ | 5 000 |

## Механика вкладов — пошагово

### Шаг 1. Выбор дела
- Каждый день гильдии предлагается одно новое дело из входящих грамот
- Лимит: **максимум 5 активных дел одновременно**
- Теоретический максимум за сезон: ~20 вложений (28 дней, заморозка 7 дней)

### Шаг 2. Беседа с дельцом
- Каждый участник задаёт дельцу **до 2 вопросов**
- Ответы видны всем членам гильдии в реальном времени
- После завершения вопросов — переход к голосованию

### Шаг 3. Голосование
- Варианты: **«Вложиться»** / **«Пропустить»**
- Окно голосования: **12 часов**
- Побеждает вариант с большинством голосов (> 50%)

| Ситуация | Результат |
|---|---|
| Большинство «за» | Вложились |
| Большинство «против» или ничья | Дело пропущено |
| Никто не проголосовал за 12 ч | Дело пропущено автоматически |
| Часть не проголосовала | Считаются только поданные голоса |

### Шаг 4. Списание Звёзд
- При решении «Вложиться» Звёзды списываются **одновременно у всех участников**
- Нельзя проголосовать «за» и не заплатить

### Шаг 5. Заморозка
- Дело живёт **7 дней** с момента вложения
- Довложить, вывести досрочно или выйти из дела **нельзя**
- По истечении 7 дней дело закрывается и результат фиксируется

## Чат гильдии

Отдельная вкладка рядом с общим чатом Ярмарочной площади.
Видят только члены гильдии. Используется для обсуждения тактики до и после беседы с дельцом.

---

## Закрытие сезона — 12 июня 23:59 МСК

Все активные дела принудительно закрываются. Результат по состоянию портфеля на этот момент.

**Итог дела по типу судьбы:**

| Судьба (ProjectFate) | Результат |
|---|---|
| UNICORN | Золотые × (1 + реальная доходность%) |
| SURVIVOR | Золотые × (1 + реальная доходность%) |
| HONEST_FAIL | Частичный возврат пропорционально дню закрытия |
| SLOW_DRAIN | Частичный возврат (−30–70% от вложения) |
| INSTANT_SCAM | 0 Золотых |

---

## Расчёт итогов гильдии

```
Вложено_гильдии  = Σ Золотых по всем делам
Итого_гильдии    = Σ итогов всех закрытых дел
Прибыль_гильдии  = Итого_гильдии − Вложено_гильдии
Доходность (%)   = Прибыль_гильдии / Вложено_гильдии × 100
```

---

## Распределение выигрыша

### Шаг 1 — Формирование котла

```
Всего_звёзд = Σ Звёзд всех участников всех гильдий за сезон
Котёл (TON) = 70% × Всего_звёзд × курс_⭐→TON на 12 июня
```

Оставшиеся **30%** — бюджет ярмарки на развитие.

### Шаг 2 — Доля каждой гильдии

Участвуют только гильдии с положительной доходностью.

```
Очки_гильдии = max(0, Доходность_гильдии %)
Доля_гильдии = Очки_гильдии / Σ Очков_всех_прибыльных_гильдий × Котёл
```

**Пример:** три прибыльные гильдии с доходностью +40%, +25%, +15%:

| Гильдия | Доходность | Очки | Доля котла |
|---|---|---|---|
| А | +40% | 40 | 50.0% |
| Б | +25% | 25 | 31.3% |
| В | +15% | 15 | 18.8% |
| **Σ** | | **80** | **100%** |

### Шаг 3 — Доля каждого участника внутри гильдии

```
Доля_участника = Звёзды_участника / Звёзды_гильдии_всего × Награда_гильдии
```

**Пример:** гильдия заработала 10 TON, состав — Мудрец (150⭐), Боярин (250⭐), Князь (500⭐):

| Участник | Вложено | Доля | Получает |
|---|---|---|---|
| Мудрец | 150 ⭐ | 16.7% | 1.67 TON |
| Боярин | 250 ⭐ | 27.8% | 2.78 TON |
| Князь | 500 ⭐ | 55.6% | 5.56 TON |
| **Σ** | **900 ⭐** | **100%** | **10 TON** |

## Граничные случаи

| Ситуация | Решение |
|---|---|
| Гильдия не набрала 3 участников к 15 мая | Не активируется, Звёзды не списываются |
| Участник не голосовал 12 часов | Его голос не учитывается |
| Все промолчали | Дело пропускается |
| Гильдия ушла в минус по итогам | Из котла не получает ничего |
| Участник недоступен на момент выплаты | TON резервируется, выплачивается при возвращении в течение 30 дней |

## Схема данных (предварительно)

```prisma
model Guild {
  id          String   @id @default(uuid())
  name        String
  createdAt   DateTime @default(now())
  seasonId    String   // привязка к сезону

  members     GuildMembership[]
  investments GuildInvestment[]
  messages    GuildMessage[]
}

model GuildMembership {
  id       Int    @id @default(autoincrement())
  guildId  String
  userId   Int
  role     String @default("MEMBER") // LEADER | MEMBER
  totalStarsInvested Int @default(0)

  guild    Guild  @relation(fields: [guildId], references: [id])
  user     User   @relation(fields: [userId], references: [id])

  @@unique([guildId, userId])
}

model GuildInvestment {
  id        String   @id @default(uuid())
  guildId   String
  projectId String
  status    String   @default("VOTING") // VOTING | ACTIVE | CLOSED
  votesFor  Int      @default(0)
  votesAgainst Int   @default(0)
  votingEndsAt DateTime
  closedAt  DateTime?
  result    Float?   // итоговый % доходности после закрытия

  guild     Guild    @relation(fields: [guildId], references: [id])
  votes     GuildVote[]
}

model GuildVote {
  id           Int    @id @default(autoincrement())
  investmentId String
  userId       Int
  vote         String // FOR | AGAINST
  createdAt    DateTime @default(now())

  investment   GuildInvestment @relation(fields: [investmentId], references: [id])

  @@unique([investmentId, userId])
}

model GuildMessage {
  id          Int      @id @default(autoincrement())
  guildId     String
  userId      Int
  text        String   @db.Text
  createdAt   DateTime @default(now())

  guild       Guild    @relation(fields: [guildId], references: [id])
}
```
