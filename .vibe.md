«Из грязи в князи» — Telegram Mini App, сказочный симулятор купца-инвестора, где перед каждым вложением игрок проходит мини-игру в стиле одного из семи архетипов хозяина (Буратино, Кощей, Колобок, Золушка, Баба Яга, Иван Дурак, Царь Горох). Активная версия — бета 4.0.1.

Стек: TypeScript + React 18 на клиенте, Vite, Pixi.js v8 для мини-игр, framer-motion для UI; Fastify + Prisma + PostgreSQL на сервере, OpenRouter (DeepSeek, Gemini) для реплик NPC, Grammy для бота, Telegram Stars для платежей, деплой на Railway.

Сейчас в фокусе семь мини-игр по архетипам и слой «отношений» с дельцами: жетоны-монетки за прокачку, ими можно бесплатно открыть беседу или раскрыть подсказку по делу при провале. Свежее — страница «Отношения», welcome-жетон за первое знакомство, дневные стрики, fullscreen-режим, защита от F5-эксплойта, переписанная Баба-Яга с котлом и взрывами.

Архитектурно: вся графика мини-игр процедурная (Pixi.Graphics, без спрайтшитов), детерминированный RNG из gridSeed; скрытые поля проекта (fate, реальная доходность) живут только на сервере, фильтруются через toPublicDTO; жетоны вычисляются на лету из БД, хранится только потраченное; таппы на Pixi-канвасе вынесены в DOM-overlay из-за пересоздания контейнеров каждый кадр.
